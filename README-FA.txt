Study Arcade PWA — راهنمای فارسی

این پوشه یک سایت استاتیک قابل نصب (PWA) است، نه فایل APK.
برای نصب به شکل اپ روی اندروید، باید سایت روی یک آدرس HTTPS منتشر شود.

روش پیشنهادی با گوشی:
1) وارد github.com شو و یک مخزن جدید بساز (مثلاً study-arcade). Public را انتخاب کن.
2) فایل‌های داخل این پوشه را در ریشهٔ مخزن بارگذاری کن؛ مهم است index.html، manifest.webmanifest، sw.js و icon.svg در ریشه باشند.
3) در مخزن، Settings > Pages را باز کن.
4) در بخش Build and deployment، گزینه Deploy from a branch را انتخاب کن؛ Branch = main و Folder = /(root)، سپس Save.
5) بعد از چند دقیقه آدرس Pages که GitHub نشان می‌دهد را باز کن.
6) در Chrome اندروید منوی سه‌نقطه را بزن و Install app یا Add to Home screen را انتخاب کن.

اطلاعات سابقه در حافظهٔ همان مرورگر/دستگاه ذخیره می‌شود. برای جلوگیری از گم‌شدن اطلاعات از دکمهٔ «خروجی گرفتن» استفاده کن.
